# Ghi chú cho bản phát hành kế tiếp — mỗi dòng bắt đầu bằng "- "
- Home Screen app (PWA) on iPhone: the header now leaves more room below the status bar / Dynamic Island.
- Phone-style notifications for Web Push and Bark: the app name as the title and one short line underneath, like native apps ("Scrypted — Update available: 0.148.6 → 0.148.8", "Nextcloud — Updated to 30.0", "3 updates available — Scrypted, Beszel, Glances"), without emoji, bullets or line breaks; Bark shows the AppManager icon.
- Web Push: tapping an "update available" notification opens the Updates list; the Home Screen app icon shows the number of apps with updates (like the App Store) and clears when there are none; Android shows a small monochrome status-bar icon.
- Fixed: after a rebuilt `latest` image of AppManager Pro, the update could be shown as an older release (e.g. "v0.25.0 → v0.24.0"). An older release name is never shown as the new version, and AppManager images now carry their real version label.
- Fixed: style sheets and scripts are now loaded with the build id, so iPhone / Safari no longer keeps an old style sheet after AppManager updates (the Home Screen header spacing did not show up).
- New sign-in page: a dark server room — press the power button on the server to boot it; its status lights blink and a holographic projector on top lights up the sign-in form. Pick the light color (amber, cyan, pink, green, white). It stays on next time, is already on for first-time setup and when there is an error to read, and works without JavaScript.
- Settings redesigned in the style of iOS settings (still Liquid Glass): large title, a Dark mode card, grouped sections with small capital labels, each row shows its current value (update schedule, channels on, two-factor on / off, Tokens…), a Language page, and a "N changes · Discard · Save" bar instead of separate Save buttons.
- Settings now open full screen: the large "Settings" title sits next to the close button, sub-pages have their title centered with back / close buttons, and the separate (i) button is gone (About is in the list).
- New Appearance page (per device, live preview, saved with the changes bar): theme color (blue, violet, pink, green, amber), text size (4 steps), UI style (rounded, soft, crisp corners), icon style (tinted, solid, mono) and the Home Screen app icon (classic, violet, pink, green, amber, graphite).
- Sign-in page: "Sign in / Create account" tabs. Create account explains that accounts are created by an administrator (no open password sign-up, to protect the Docker server) and offers "Create account with <provider>" when single sign-on creates accounts automatically.
- Sign-in page: "Or continue with" section — the single sign-on button now shows the provider's icon (Google, Authentik, Keycloak, Authelia, GitLab, Okta, Auth0, Cloudflare Access, Nextcloud or OpenID); when single sign-on is off it explains how an administrator turns it on.
- Sign-in page: the light beam now scrolls together with the projector on short screens.
- Appearance → UI style now changes the whole app the way its sample shows: Rounded makes buttons, inputs and chips pill-shaped with rounder cards, Soft is the original design (default), Crisp uses small corners.
- First run: no separate "create admin" screen any more — the normal sign-in page is shown and the administrator account is created in the Create account tab (marked with a dot while the machine has no account). Once an administrator exists, Create account explains how to get an account here or on another machine (ask its administrator for an account or an API Token for Settings → Servers).
- README: new "Accounts & signing in" guide (first run, adding people and roles, single sign-on, managing another machine, resetting the administrator password with RESET_AUTH).
- Security: the first administrator can only be created while the machine has no account at all (fresh install, or after RESET_AUTH); the check and the creation now happen in one database transaction, so simultaneous requests cannot create two administrators.
- Home Screen app (PWA) on iPhone: the status bar is now solid (black in dark mode, white in light mode) instead of see-through, so the page starts right below the clock / battery — nothing is cut off under the Dynamic Island and no empty gap is needed. Settings → About shows a small display diagnostics line (Home Screen app or browser, safe area, header spacing, build).
- Sign-in page on computers: no more empty area below the page after the window is made smaller.
- Sign-in page: when the server is switched on, the whole room (edges and corners included) now glows softly in the light color instead of a hard cone or frame around the form, with glowing specks that twinkle and float upward.
- New Settings → Cache page that explains what each cache is and when to clear it. This device: "Clear & reload" the interface (fixes a Home Screen app or browser still showing an old design after an update; keeps sign-in, settings and Web Push) and reset the appearance settings. On the server (administrators): network cache (Docker Hub / GitHub answers), saved changelogs and check results (versions and update rules are kept, then everything is checked again), single sign-on provider cache, CPU / RAM chart data, and a shortcut to the Docker cleanup in Storage & SSD. Every server cache shows its size and asks for confirmation first.
- Settings: sub-pages always open at the top, and going back returns to the same place in the list (Cache and About used to open scrolled to the bottom).
